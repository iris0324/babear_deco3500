# Borrowed Eyes V3 — 12 幅原作 / 60 个细节挑战

## 打开

直接打开 index.html，或使用单独交付的 BorrowedEyes_12幅60细节预览.html。作品和界面图像都在本地，无需联网加载；馆藏来源链接需要联网访问。

## 本次修改

- 清晰度更新：12 幅替换为官方原始图，长边约 1937–4000 像素；细节按源像素约 1.5 倍密度限制展示，最大 480×420 CSS 像素，避免小选区铺满大屏。裁剪区域、面积和星级保持不变。

- 12 幅细节丰富的群体、室内、城市、自然场景，移除上一版中容易直接识别的梵高头像、梵高麦田、大浪和维米尔单人场景。
- 前三幅原作各有 8 个挑战，其余 9 幅各有 4 个挑战，共 60 张。每张有独立 ID、裁剪矩形、面积、难度、任务标题、个人感受和线索。
- 原作 ID 用于判题；细节 ID 用于任务、进度和奖励。同一原作不同细节接受同一个正确作品答案。重复同一细节不重复奖励。
- 发布者可在既有原作上新增细节，不会因此增加一幅重复原作。
- 五星细节经过目视检查，主要为远处小建筑、稻草、树皮、家具、植物、器物、织物、冰、船沿等，避开完整人脸与标志性主体。空白天空或地板等不可辨认区域已替换。
- 默认高星级优先，支持类别与星级组合筛选，每页 12 张。

## 难度按百分比自动计算

裁剪百分比 = (裁剪宽 × 裁剪高) ÷ (原作图像宽 × 原作图像高) × 100%。

| 难度（从低到高） | 裁剪面积占原作 | 本版数量 |
|---|---|---|
| ★ | 80%–100% | 3 |
| ★★ | 60%–不足80% | 3 |
| ★★★ | 40%–不足60% | 12 |
| ★★★★ | 20%–不足40% | 12 |
| ★★★★★ | 大于0%–不足20% | 30 |

0% 无效。档位沿用已确认的 20% 边界。高难度可以只截取0.42%等小区域；低星级会刻意给出更完整的构图，这是较容易的入门任务。

原作图像的有效画面范围由 imageBounds 配置，排除照片里的画框及校色条。星级以该有效画面为分母；裁剪渲染与创建页使用同一个范围。源文件不变，页面用 SVG 按精确矩形显示选区，不会因卡片统一比例而额外截掉或拉伸内容。

## 规则保留

Borrow 正式次数 = 难度 + 1 − 人数。Blind 正式次数 = 难度 + 1。签到、地图查看不消耗次数。Borrow 每位成员只能评论解锁一条；Blind 错误后依次解锁。Q5 只提示四区域之一。

## 运行范围

六套前端流程继续保留。账户、真实多人匹配、聊天和位置验证仍是本地演示，不包含服务器服务。真实浏览器定位权限成功也不会自动冒充教室验证。

首次打开使用新的 V3 存储键，避免把旧版8幅作品的编号及进度套到新库。
