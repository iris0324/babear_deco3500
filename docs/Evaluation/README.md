# Evaluation

This folder documents the evaluation of our prototypes across different design iterations.

Each evaluation round includes:

- the testing plan;
- testing materials and evidence;
- key findings;
- design implications.

## Evaluation Rounds

### Round 2 — Borrowed Eyes Paper Prototype

Round 2 evaluates the core Borrowed Eyes interaction in a physical gallery.

The evaluation focuses on:

- artwork search and closer observation;
- independent interpretation;
- comparison with another visitor's perspective;
- re-observation;
- visitor contribution;
- clue usability.
